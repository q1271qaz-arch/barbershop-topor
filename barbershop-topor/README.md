БАРБЕРШОП «ТОПОР» — финальная статическая версия

Запуск:
1. Откройте папку barbershop-topor в VS Code.
2. Установите расширение Live Server.
3. Нажмите правой кнопкой по index.html → Open with Live Server.

EmailJS и Яндекс Карты требуют ваших ключей. До их настройки форма использует тестовую отправку, если она была включена в booking-form.js.
